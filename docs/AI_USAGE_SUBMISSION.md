## Description

We used GPT-6.1 Sol through Codex to build Jinni within the hackathon time. At least one team member used paid access. AI generated most backend and interface code, synthetic datasets, tests, documentation and presentation materials. Theo directed backend work; Wahab directed frontend and Electron work. We set requirements and reviewed generated code, but did not regularly edit it by hand. Our AI usage level is 5, Vibe coded. We checked output with linting, boundary and two-source integration tests, browser/Python parity and actual Electron runs. The final checks passed 677 Python tests, 93 desktop unit tests and 36 Electron checks. Automated AI responses were mocked. Separately, two live DeepSeek deepseek-flash requests passed a cited-answer check and returned two cited proposals without changing the calculated comparison. Comparison scores use deterministic rules, not an LLM. AI answers and proposals use selected source passages with checked exact quotations. These checks establish quote membership, not the truth of every claim. Built-in datasets are fictional; provider keys use OS-encrypted device storage. Source or provider failures produce visible errors.
