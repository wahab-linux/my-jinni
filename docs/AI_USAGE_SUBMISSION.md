## Description

We used Codex, including coordinated coding agents, to plan, implement, debug, test and document Jinni, turning our requirements into a working prototype within the hackathon time. AI produced most of the implementation, mock datasets, adapters, tests and demo materials. Theo owned the backend and Wahab the interface. We provided product requirements and reviewed much of the generated code, but did not regularly edit AI output by hand. Changes were checked by running the application and automated tests, with further prompting for fixes. Verification covered boundaries, two-source integration, browser/Python parity and real Electron/Chromium runs. Automated provider responses were mocked; a separate authorised live DeepSeek check passed answer and option-proposal citation checks without changing deterministic results. Comparisons use explicit measurements and deterministic rules without AI. Optional AI uses selected evidence; exact-quote checks aid inspection but do not prove every claim. Built-in datasets are fictional, keys remain session-only, and invalid or unavailable sources/provider output fail visibly.
