Import limits & privacy

Up to 20 sources · TXT, Markdown or text PDF · 5 MiB each · 150,000 characters · 40 PDF pages. Nothing is sent to an AI provider. This library is separate from the desktop app. Clearing site data removes it; download important sources to keep a copy.
